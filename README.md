### Запуск front:  
python3.12 -m http.server 2000


### Запуск backend (из папки jakarta-base):  
./mvnw wildfly:dev

WildFly отдельно запускать и скачивать не надо.  
Он скачается и сам запустится благодаря Maven плагину

### Стек бекенда:
- JDK 21
- JakartaEE 11
- Maven
- WildFly
